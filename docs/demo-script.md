# 两分钟演示脚本

先启动服务，打开 `http://127.0.0.1:8000/`。默认买家 B，界面标记离线模板模式。

1. **0:00–0:20，政策问答**：点“政策问答”。说明签收次日起算；中栏显示政策依据，右栏 P01 可追溯。
2. **0:20–0:35，会追问**：点“信息追问”。需要订单和原因，不能在没有订单时给退货结论。
3. **0:35–1:00，知道停**：点“订单退款”。ORD-1004 实付 1280 元，金额检查 1280 > 500，
   R1 强制转人工；显示真实创建的模拟工单，不能承诺退款结果。
4. **1:00–1:15，投诉处理**：点“投诉转人工”。R3 处理新的投诉事项；历史轨迹继续向下追加。
5. **1:15–2:00，可复盘**：点“跑评测”。只展示实际任务进度和结果，等待完成后说明离线成绩；
   展开 E08，展示工单经接口查验，随后展开 F-MONEY-001 查看真实失败及修复前后。

如果出现失败，直接展示红色判据和实际回复，不隐藏或篡改报告。
真实模型模式需配置服务端环境变量，并另跑一轮；不能把离线结果当成真实模型结果。
服务重启后需要重置聊天；已保存评测报告仍可读取。
